# Vectors, Coordinates, and Objects
Pinnacle uses a 3d spherical and rectangular coordinate vector system in order to properly calculate movement in
3 dimensions, and 2d polar and rectangular coordinate vector system in 2 dimensions. Although an object could be
represented as a simple pair of vectors, Pinnacle chooses to use rectangular coordinates, a velocity vector, a mass,
and a shape in order to define every object. This allows for objects to be extremely small memory wise, without loosing to many
options in physical calculations and interactions.
